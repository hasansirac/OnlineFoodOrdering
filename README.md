# Online Food Ordering System

This project is an Online Food Ordering System developed in Java using Object-Oriented Programming (OOP) principles.

## Features
* **User Authentication:** Secure login system for customers.
* **Menu Management:** Dynamic menu items with categories and prices.
* **Order Processing:** Real-time order creation and total calculation.
* **Payment Integration:** Polymorphic payment system supporting Credit Card and Cash.

## Technologies Used
* **Language:** Java (JDK 17+)
* **Concepts:** Inheritance, Polymorphism, Interfaces, Encapsulation
* **Version Control:** Git & GitHub

## How to Run
1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Run the `Main.java` file to simulate the ordering process.
